## 1. ブログと書き手

- サイト名「えとくらし」。個人サイトのブログ欄。書き手は Chihiro（クリニック勤務の看護師、筋トレ・推し活・ゼンゼロ・ジョジョ・クラシック・星・自作小説など）。
- SNS のしがらみから離れたくて作ったサイトで、ブログは「たっぷり時間をかけて自分の言葉をつむげる」場所だと本人が書いている（id 6, 9）。
  → 読みやすさのために手を入れても、**本人の言葉で書かれている感覚**を奪わないことが一番大事。
- 読者はスマホで読むことが多い。一文ごとの改行はそのための読みやすさでもある。
- 本文の先頭約100字が、検索結果に出る説明文（meta description）になる（blogdetail.html）。

## 2. 記事の骨組み

ほとんどの記事が次の流れになっている。

1. **つかみ**：「どうも、〇〇なChihiroです。」＋そのリアクション 1〜3行
2. **導入**：今日なにを書くのか、なぜ書くのか（近況・きっかけ）
3. **本編**：エピソードや語りたいこと。時系列か、項目ごと（「まずは〜」「次に〜」「あとは〜」）
4. **気づき・まとめ**：体験から思ったこと。「結果的に」「とにかく思うのは」「とはいえ」などで入る
5. **締めの一言**：冒頭やタイトルへの呼び戻し、読者への一言、決意、叫び

例（id 47「なくても生きていける」）：
iPad を売って四万円 → 手放して一か月の変化（寝る前・文字入力・スクリーンタイム）→ 手放してよかった → まだスマホという強敵 → 「宣言どおり、私はきみがいなくても、ちゃんとやっていけてるよ、iPad mini。／そして四万円、ほんとうにありがとう。」

例（id 48「秋は飽きない！」）：
予防接種のつかみ → 秋の好きなところ → 一番の理由は星 → 子どものころの星の思い出 → 今の星との付き合い方 → 「みなさんも、たまには夜空を見上げてみてはいかがでしょう？」

## 3. 冒頭

- 基本形は **「どうも、〈最近の出来事 or 今日のテーマにひっかけた自己紹介〉Chihiroです。」**（id 10 以降はほぼこれ）。
  - 「どうも、職場でいの一番にインフルエンザの予防接種を受けたChihiroです。」
  - 「どうも、ジョジョ七部のOPだけ観た女、Chihiroです。」
  - 「どうも、貧弱人間のChihiroです。」
  - 「どうも、Chihiroです。」（ひっかけなしもある）
- 〈 〉の部分は、本題と少しずらした近況や、自虐・誇張で笑いを取ることが多い。本題そのものを説明しすぎない。
- 直後に短いリアクションが続く：「臨時収入ありがてぇ〜！」「ええ、ナルシストです。」「神です、まじ嬉しいです、発狂しそうです。」
- 例外：思考カテゴリや感想羅列は「どうも」なしで本題から入ることがある（id 15, 24, 25）。

## 4. 締め

型はいくつかある。原稿にある締めの一文は、たいてい書き手の一番言いたいことなので、**残す・最後に置く**のが基本。

- **呼び戻し**：冒頭やタイトルのモチーフに戻る（id 47「四万円、ほんとうにありがとう」）
- **読者への一言**：「みなさんも、たまには〜してみてはいかがでしょう？」「〜ですよ。」
- **決意・抱負**：「〜していきたい所存です」「〜と思います」「〜目指して筋トレ頑張っていこうと思います」
- **叫び・ノリ**：「わはーーーSBR楽しみやーーー！！！！！」「筋トレはいいぞぉ！」「誰か私を殴ってくれ。」
- **ネタの引用でオチ**：「覚悟はいいか？　俺はできてる。」「十年経っても、厨二病は治らないらしい。」
- **しみじみ**：「私、彼女に会えてほんとに良かった。」

気づきを一般論っぽく述べたあとに、くだけた一言でオチをつける流れがよくある（id 38：迷走神経反射の話 → 「だからやっぱり、外来看護師にも座るための椅子が必要だと思うんですよ、ええ。」）。

## 5. 改行・段落・空行

数値は id 10〜48 の集計。

- **一文一行**。句点「。」「！」「？」のあとで改行する。1行の平均は約34字、中央値31字。
  60字を超える行はまれ。ただし感情が爆発して読点で畳みかける長い行（羅列）はわざとなので残す。
- **段落は 2〜5 行**が中心（平均3.7行）。1行だけの段落は、オチ・強調・場面の切り替えに使う。
- **空行1つ**：段落の区切り（同じ話題の中で、少し視点が変わる）。
- **空行2つ**：大きな場面転換。つかみ→本編、本編→まとめ など。1記事に1〜2回程度。
- **空行4つ以上**：ネタバレ・センシティブ注意の直後。プレビューで中身が見えないようにするため。
- 見出し（##）、箇条書きの記号（・や-）、太字は使わない。項目を並べたいときは「まずは〜。」「あとは〜ですね。」で段落を立てる。
- 本文中の HTML は改行（<br>）とたまのリンク（<a href='…' target='_blank'>）だけ。

## 6. 語り口

- 地の文は**です・ます調**。ただし独り言・ツッコミ・心の声は普通体や崩した口調が混ざる。この混ざり方が持ち味。
  - 「ブルーライトと情報の波、恐るべしです。」
  - 「うへへ、使い道はゆっくり考えようと思います。」
  - 「すぅーーっと血が失せていく感覚に『やべえ、死ぬかもしれねえ』と思いながらも〜」
  - 「……何言ってるのかわからねぇと思うが、俺もこれで伝わるとは思わねぇ。」
- 文末は「〜ですね。」「〜なんです。」「〜んですよね。」「〜けどね。」「〜かも。」「〜です、ええ。」が多い。
- 自分へのツッコミ・自虐・誇張（「数億年ぶりにメイクしました」）で笑いを作る。
- ジョジョ・アニメ・ネットのミーム、オタク語（「尊い」「エッッッ」「小並感」）を自然に使う。推し・作品の記事ほど多い。
- 体験の具体的なディテール（数字、商品名、アプリ名、セリフ）が多く、それが読ませる力になっている。削らない。
- 説教くさくならない。気づきは「〜と思うんですけどねぇ」「〜だと思う今日この頃です」くらいの温度で言う。
- 使わないもの：「いかがでしたか？」「まとめると」「〜と言えるでしょう」「〜することが大切です」のような記事テンプレ口調、ビジネス文書の硬い接続詞（しかしながら・したがって・以上のことから）、絵文字、（笑）や w。

## 7. 表記

迷ったときの多数派。原稿が逆の表記でも、明らかな揺れでなければ原稿どおりでよい。

| ひらがな寄り | 漢字寄り |
|---|---|
| ほんとう（本当は少数）、ぜんぶ、なにか、たくさん、いろいろ、すでに、すごい、わかる、できる、こと、ため | 一番、素敵、綺麗、嬉しい、面白い、今日、可愛い（かわいいも多い）、私 |

- 数：文中の数量は**漢数字**が基本（四万円、二か月半、一時間、六日間、50㎏ のように単位つきの測定値は算用数字のこともある）。
- 「……」は三点リーダー2つ。「…」1つや「...」は使わない。
- 「！」「？」のあとに文が続くときは全角スペース：「きたね……！　この季節が……！」
- 「」：セリフ、心の声、強調したい言葉。
- 『』：作品名・アプリ名・本の題名・曲名（『スカイガイド』『おまえうまそうだな』）。
- 伸ばし棒は「〜」と「～」が混在している。原稿にあるほうに合わせる。
- 「観る」は映像作品・配信、「見る」はそれ以外。
- 「Chihiro」は半角英字。

## 8. タイトルとカテゴリ

- タイトルは短く、言い切りかノリ。4〜10字程度が多い。
  例：「秋は飽きない！」「なくても生きていける」「砂糖絶許」「BLは飯」「筋肉万歳」「推しの声ってすげー！」「フェチを、語る。」「健診楽しい」「ありがてぇ」
  - だじゃれ（秋は飽きない）、四字熟語っぽい造語（砂糖絶許）、言い切り（BLは飯）、叫び（SBR楽しみや！！！）。
  - 内容を説明しすぎない。本文の締めの一言や、記事の核になるフレーズから取ることが多い。
- カテゴリは次の5つから選ぶ：
  - **日常**：生活・家族・健康・お金・スマホ断ちなど
  - **趣味**：アニメ・ゲーム・音楽・筋トレ・星・メイクなど好きなもの
  - **仕事**：看護・職場・転職
  - **推し**：推し（配信者・声）への感情、配信の感想
  - **思考**：考えごと・内省が中心の記事

## 9. 特殊な型

- **感想羅列**（id 5, 25）：配信や作品を観ながらの感想を、時系列で短く並べる。冒頭で「簡単で雑な感想羅列記事です」と断る。文はかなり崩れていてよい。再編は「時系列を揃える」「重複を削る」くらいに留める。
- **推し・作品語り**（id 3, 36, 44）：「まずは〜！」「ではお次に〜。」で対象ごとにパートを分け、空行2〜3つで区切る。熱量が命なので、勢いのある羅列・叫びは削らない。
- **ネタバレ・センシティブ注意**：「以下、ネタバレになると思うので〇〇未履修者はブラウザバックどぞ。」「センシティブ注意です。」のあと、空行を4つ以上入れてから本編。
- **思考**（id 15, 24, 34）：「どうも」なしで問いから入ったり、だ・である調の静かな文体（id 15）になったりする。原稿がその調子なら、です・ますに直さない。
- **広告・アフィリエイトリンクを含む記事**：posts-data.js では `pr: true` を付ける（記事冒頭に PR 表記が出る）。

## 10. 文体の変遷

- id 1〜9（2026年7月〜8月頭）は「こんにちは」始まりや、一段落に複数の文を詰める書き方が混じっていた。
- id 10 以降で「どうも、〜Chihiroです。」＋一文一行のスタイルが定着した。
- 再編のお手本にするのは **id 10 以降、とくに直近の記事**。
